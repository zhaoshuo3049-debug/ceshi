# 移除表格行展开功能计划

## Summary
移除职位列表表格左侧的展开下拉箭头，使表格行不可展开。

## Current State Analysis
在 `src/pages/JobList/index.tsx` 中：
- `expandedRowKeys` 状态用于控制展开行（第 42 行）
- `expandedRowRender` 函数定义了展开行的渲染内容（第 318 行）
- Table 组件配置了 `expandable` 属性（第 639–656 行），包括：
  - `expandedRowKeys` 和 `onExpandedRowsChange` 控制展开状态
  - `expandedRowRender` 渲染展开内容
  - `columnWidth: 36` 设置展开列宽度
  - `expandIcon` 自定义了下拉箭头图标（`DownOutlined`/`RightOutlined`）
- `DownOutlined` 和 `RightOutlined` 从 `@ant-design/icons` 导入，仅用于展开图标
- `styles.css` 中有 `.ant-table-row-expand-icon-cell` 的样式覆盖，用于调整展开列的内边距

## Proposed Changes

### 1. `src/pages/JobList/index.tsx`
**What**：移除 Table 组件的 `expandable` 配置、展开行渲染函数及相关状态。
**Why**：用户要求列表去掉下拉箭头，不可展开。
**How**：
- 删除 `expandedRowKeys` 状态声明（第 42 行）
- 删除 `expandedRowRender` 函数定义（第 318–354 行）
- 删除 Table 组件的 `expandable` 属性（第 639–656 行）
- 删除 `DownOutlined` 和 `RightOutlined` 从 `@ant-design/icons` 的导入

### 2. `src/pages/JobList/styles.css`
**What**：删除展开列相关的 CSS 覆盖。
**Why**：展开列已不存在，对应的样式不再需要。
**How**：
- 删除 `.ant-table-row-expand-icon-cell` 样式块（第 477–479 行）

## Assumptions & Decisions
- 完全移除展开功能，不保留仅隐藏图标的方案。
- 不调整其他列的宽度或顺序。

## Verification Steps
1. 启动开发服务器，打开职位列表页面。
2. 确认表格左侧不再显示展开/折叠箭头。
3. 确认点击表格行不会展开详情内容。
4. 确认页面无编译错误，表格布局正常。
