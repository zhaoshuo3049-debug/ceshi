# 筛选区域布局重构计划

## Summary

将职位列表页面搜索区域的控件重新分排布局：所有文本输入类控件（搜索框、交付经理、交付顾问）统一放在第一行；所有选择类控件（全词匹配、推荐节点、是否分配、是否concall）统一放在第二行。同时移除所有 `size="small"` 配置，统一所有输入框高度为 Ant Design 默认尺寸（middle），确保视觉一致。

## Current State Analysis

当前搜索区域分为两行 + 已选筛选栏：

- **第一行**：搜索框（Select + Input）+ 全词匹配（Checkbox）+ 推荐节点（Select）+ 是否分配（Select）
- **第二行**：交付经理（Input, size=small）+ 交付顾问（Input, size=small）+ 是否concall（Select, size=small）
- **第三行**：已选筛选标签 + 订阅/清空按钮（status-filter-row）

**高度不一致问题**：
- 搜索框 Input 为默认 middle 尺寸（~32px），外层 `.search-input-group` 有 1px border，总高度约 34px
- 交付经理、交付顾问 Input 使用 `size="small"`（~24px）
- 是否concall Select 使用 `size="small"`（~24px）
- 推荐节点、是否分配 Select 为默认 middle 尺寸（~32px）

这导致第二行的输入框明显矮于第一行，视觉不协调。

## Proposed Changes

### 1. `src/pages/JobList/index.tsx` — 控件重新分排

#### 第一行（search-row）：所有文本输入框
将以下控件放入第一行的 `.search-row` 中：
- 搜索框（保留原有的 `.search-input-group` 组合结构）
- 交付经理 Input：从第二行移至第一行
- 交付顾问 Input：从第二行移至第一行
- **移除**交付经理和交付顾问的 `size="small"` 属性，使其使用默认 middle 尺寸

修改后第一行结构：
```
<div className="search-row">
  <div className="search-input-group"> ... </div>
  <div className="filter-item">
    <Input placeholder="输入交付经理并回车" ... />
  </div>
  <div className="filter-item">
    <Input placeholder="输入交付顾问并回车" ... />
  </div>
</div>
```

#### 第二行（search-row）：所有选择类控件
将以下控件放入第二行的 `.search-row` 中：
- 全词匹配（Checkbox）：从第一行移至第二行
- 推荐节点（Select）：从第一行移至第二行
- 是否分配（Select）：从第一行移至第二行
- 是否concall（Select）：保留在第二行
- **移除**是否concall Select 的 `size="small"` 属性

修改后第二行结构：
```
<div className="search-row">
  <div className="filter-item"><Checkbox ...>全词匹配</Checkbox></div>
  <div className="filter-item">
    <span className="filter-label">推荐节点</span>
    <Select ... />
  </div>
  <div className="filter-item">
    <span className="filter-label">是否分配</span>
    <Select ... />
  </div>
  <div className="filter-item">
    <span className="filter-label">是否concall</span>
    <Select ... />
  </div>
</div>
```

#### 第三行（status-filter-row）
保持现有逻辑不变：动态展示已选筛选标签，支持单个移除和一键清空。

### 2. `src/pages/JobList/styles.css` — 高度统一与样式清理

#### 统一控件高度
- 移除交付经理、交付顾问、是否concall 的 `size="small"` 后，所有 Input/Select 默认高度均为 32px
- 搜索框组合 `.search-input-group` 当前由内部 Input 撑开高度（约 34px，含 border），需调整使其与其他 32px 控件对齐

**具体 CSS 调整**：
1. `.search-input-group`：显式设置 `height: 32px; box-sizing: border-box;`，让 border 被包含在 32px 内，使总高度与其他控件一致
2. `.search-type-select` 和 `.search-main-input`：设置 `height: 100%;`，使其填满 32px 容器（Ant Design 内部样式需覆盖，确保不溢出）
3. `.filter-item`：保持 `display: flex; align-items: center;`，确保行内所有控件垂直居中
4. `.search-row`：保持 `align-items: center; gap: 12px;`，控件间距不变

#### 清理无用样式
- `.search-btn` 样式块：搜索按钮已在之前迭代中移除，其对应 CSS 样式块可安全删除

## Assumptions & Decisions

1. **控件分类标准**：文本输入框（搜索框、交付经理、交付顾问）归为"搜索项"放第一行；选择类控件（Checkbox、Select）归为"选择项"放第二行。此分类已与用户确认（方案A）。
2. **统一尺寸策略**：移除所有 `size="small"`，统一使用 Ant Design 默认 middle 尺寸（32px），视觉上最协调且无需引入额外尺寸枚举。
3. **搜索框组合高度处理**：通过给 `.search-input-group` 显式设置 `height: 32px` + `box-sizing: border-box`，将外层 border 纳入总高度，使组合框与普通 Input/Select 的 32px 严格对齐。
4. **回车触发逻辑不变**：搜索框、交付经理、交付顾问的回车触发逻辑保持现有实现（使用临时输入状态，回车后赋值给实际筛选状态）。

## Verification Steps

1. 刷新页面，确认搜索区域第一行从左到右依次为：搜索框、交付经理输入框、交付顾问输入框
2. 确认第二行从左到右依次为：全词匹配、推荐节点、是否分配、是否concall
3. 检查所有输入框和选择框的高度是否一致（目测对齐，无明显高低差）
4. 在交付经理和交付顾问输入框中输入内容按回车，确认筛选生效
5. 在搜索框中输入内容按回车，确认搜索生效
6. 使用清空按钮，确认所有筛选条件（包括输入框临时状态）被正确重置
