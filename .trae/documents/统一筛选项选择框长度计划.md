# 统一筛选项选择框长度计划

## Summary
将职位列表筛选区域中"职位状态"、"是否分配"、"是否concall"三个 Select 选择框的宽度统一为一致，提升界面整齐度。

## Current State Analysis
在 `src/pages/JobList/index.tsx` 的筛选区域（第 569–615 行）：
- **职位状态**：`mode="multiple"`，当前 `style={{ width: 200 }}`
- **是否分配**：单选，当前 `style={{ width: 120 }}`
- **是否concall**：单选，当前 `style={{ width: 120 }}`

三个选择框宽度不一致，导致第二行筛选区域视觉上不整齐。

## Proposed Changes

### 1. `src/pages/JobList/index.tsx`
**What**：将三个 Select 组件的内联宽度统一调整为 `160px`。
**Why**：160px 能在保证多选框有足够展示空间的同时，与单选框保持视觉一致，且符合界面紧凑性的偏好。
**How**：修改三处 `style` 属性：

```tsx
// 职位状态（第 579 行）
style={{ width: 160 }}

// 是否分配（第 595 行）
style={{ width: 160 }}

// 是否concall（第 610 行）
style={{ width: 160 }}
```

## Assumptions & Decisions
- 统一宽度定为 **160px**，兼顾多选标签展示空间与单选框的紧凑感。
- 不修改 `.filter-select` 的 `min-width: 120px`，因为 `style={{ width: 160 }}` 的优先级更高，且保留 `min-width` 可在未来需要时提供下限保护。

## Verification Steps
1. 启动开发服务器，打开职位列表页面。
2. 查看第二行筛选区域，确认"职位状态"、"是否分配"、"是否concall"三个选择框的宽度视觉上完全一致。
3. 横向对比三者的下拉框展开宽度，确认均为 160px。
