# 调整职位名称列左侧间距计划

## Summary
为表格首列"职位名称"增加左侧内边距，使其不要过于贴边，保持合理的左侧间距。

## Current State Analysis
在 `src/pages/JobList/index.tsx` 中：
- "职位名称"列是表格首列（第 211–219 行），使用自定义的 `job-name-cell` 类渲染内容

在 `src/pages/JobList/styles.css` 中：
- `.job-name-cell` 当前为 flex 布局，无左侧内边距（第 271–276 行）
- `.table-section .ant-table-thead > tr > th` 和 `.table-section .ant-table-tbody > tr > td` 的单元格内边距为 `12px 8px`，左右均为 8px
- 由于已移除复选框列和展开列，"职位名称"列现在是表格最左侧的列，内容直接贴近表格左边缘，视觉上显得太靠左

## Proposed Changes

### 1. `src/pages/JobList/styles.css`
**What**：为 `.job-name-cell` 增加左侧内边距。
**Why**：让职位名称文本与表格左边缘保持合理间距，改善视觉体验。
**How**：在 `.job-name-cell` 样式中增加 `padding-left: 12px`：

```css
.job-name-cell {
  display: flex;
  align-items: center;
  padding-left: 12px;
}
```

## Assumptions & Decisions
- 仅调整内容单元格的左侧间距，不修改表头样式。如果表头也需要对齐，可以进一步为表头对应的 `th` 增加左内边距。
- 采用 12px 的左内边距，与其他组件的间距规范保持一致。

## Verification Steps
1. 启动开发服务器，打开职位列表页面。
2. 查看"职位名称"列首行内容，确认左侧有合理间距，不再紧贴表格左边缘。
