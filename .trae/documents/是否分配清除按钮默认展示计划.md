# 是否分配清除按钮默认展示计划

## Summary

将"是否分配"筛选条件（Ant Design Select 组件）的清除按钮从默认的"鼠标悬浮才展示"改为"默认始终展示"。仅修改该字段，不影响其他 Select 组件。

## Current State Analysis

- "是否分配"字段使用 Ant Design `Select` 组件，配置了 `allowClear` 属性
- Ant Design Select 的清除按钮默认行为是：仅在鼠标悬浮到 Select 上时才显示，移开后隐藏
- 该 Select 当前的 `className` 是通用的 `"filter-select"`，与其他 Select 共用同一类名
- 已选筛选标签（status-tag）中的关闭按钮一直可见（opacity 0.6），不属于本次修改范围

## Proposed Changes

### 1. `src/pages/JobList/index.tsx` — 添加特定类名

给"是否分配"Select 的 `className` 追加一个独立标识类，便于精准定位样式：

```tsx
<Select
  placeholder="请选择"
  allowClear
  className="filter-select is-assigned-select"
  value={isAssigned}
  onChange={setIsAssigned}
  style={{ width: 120 }}
>
  <Option value="yes">已分配</Option>
  <Option value="no">未分配</Option>
</Select>
```

### 2. `src/pages/JobList/styles.css` — 覆盖清除按钮显示逻辑

添加 CSS 规则，强制该 Select 的清除按钮始终可见：

```css
.is-assigned-select.ant-select-allow-clear .ant-select-clear {
  opacity: 1;
}
```

Ant Design 默认通过控制 `opacity` 实现悬浮显示/隐藏，将其固定为 `1` 即可使清除按钮默认展示。

## Assumptions & Decisions

1. **目标元素确认**：用户所指的"关闭按钮"是 Ant Design Select 组件在 `allowClear` 状态下的清除按钮（× 图标），而非已选筛选标签中的 remove-icon。已选标签的 remove-icon 本身已默认可见。
2. **隔离修改**：通过追加独立类名 `.is-assigned-select` 实现样式隔离，确保其他 Select（职位状态、是否concall 等）的清除按钮行为不受影响。
3. **覆盖方式**：Ant Design Select 清除按钮的显隐由 `opacity` 控制，直接覆盖 `opacity: 1` 是最轻量、最稳定的方案。

## Verification Steps

1. 刷新页面，查看"是否分配"Select
2. 选择"已分配"或"未分配"后，确认清除按钮（×）在不悬浮时也可见
3. 确认其他 Select（职位状态、是否concall）的清除按钮仍保持默认悬浮展示行为
