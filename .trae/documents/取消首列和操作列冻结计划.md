# 取消列表首列和操作列冻结计划

## Summary
移除职位列表表格中首列（复选框列）和操作列的冻结效果，使其随表格内容一起滚动。

## Current State Analysis
在 `src/pages/JobList/index.tsx` 的表格列配置中：
- 首列（复选框列）设置了 `fixed: 'left'`（第 226 行）
- 操作列设置了 `fixed: 'right'`（第 370 行）
- 职位名称列仍保留 `fixed: 'left'`，不在本次调整范围内

## Proposed Changes

### 1. `src/pages/JobList/index.tsx`
**What**: 移除首列和操作列的 `fixed` 属性。
**Why**: 用户要求首列和操作列不再冻结，使其随表格横向滚动。
**How**:
- 删除首列配置中的 `fixed: 'left'` 行
- 删除操作列配置中的 `fixed: 'right'` 行

具体修改位置：
```tsx
// 首列（复选框列）
{
  title: <Checkbox ... />,
  key: 'checkbox',
  width: 40,
  // 删除: fixed: 'left',
  render: (_, record) => (...),
}

// 操作列
{
  title: '操作',
  key: 'action',
  width: 60,
  // 删除: fixed: 'right',
  align: 'center',
  render: () => (...),
}
```

## Assumptions & Decisions
- 职位名称列保留 `fixed: 'left'`，仅按用户字面要求调整首列和操作列。
- 不修改 `styles.css` 中的 `.ant-table-cell-fix-left` / `.ant-table-cell-fix-right` 样式，因为职位名称列仍使用左侧冻结，这些样式仍然有效。

## Verification Steps
1. 启动开发服务器，打开职位列表页面。
2. 横向滚动表格，确认首列（复选框列）和操作列不再固定，随内容一起滚动。
3. 确认职位名称列仍然保持左侧冻结。
