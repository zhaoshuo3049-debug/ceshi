# 加大搜索类型下拉框宽度计划

## Summary
将第一行搜索区域中搜索类型下拉框（全文/职位名称/客户名称/联系人）的宽度从 80px 加大到 120px，解决选项文字展示不全的问题。

## Current State Analysis
在 `src/pages/JobList/styles.css` 中：
- `.search-type-select` 当前宽度为 `80px`（第 55 行）
- 该下拉框选项包含 4 个汉字（如"职位名称"、"客户名称"），在 80px 宽度下加上 Select 组件的内边距和箭头图标，文字会被截断显示不全
- `.search-input-group` 的 `max-width` 为 400px，搜索类型加宽后输入框仍有充足空间，无需调整整体容器宽度

## Proposed Changes

### 1. `src/pages/JobList/styles.css`
**What**：将 `.search-type-select` 的宽度从 `80px` 调整为 `120px`。
**Why**：120px 足够完整展示 4 个汉字的选项文字（"职位名称"、"客户名称"），同时保留合理的内边距和箭头图标空间。
**How**：修改第 55 行：

```css
.search-type-select {
  border: none !important;
  background: #f5f7fa;
  border-radius: 0 !important;
  width: 120px;  /* 从 80px 调整 */
  height: 100%;
}
```

## Assumptions & Decisions
- 仅调整搜索类型下拉框自身的宽度，不改动 `.search-input-group` 的 `max-width: 400px`，因为输入框剩余空间（约 280px）仍然充裕。
- 不调整其他筛选条件或下拉框的宽度。

## Verification Steps
1. 启动开发服务器，打开职位列表页面。
2. 点击搜索框左侧的下拉框，切换选项到"职位名称"和"客户名称"。
3. 确认选项文字在下拉框中完整展示，无截断或省略号。
