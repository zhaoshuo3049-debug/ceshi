# 移除复选框列及三字段列计划

## Summary
从职位列表表格中移除复选框列以及"画像描述"、"业务部门简介"、"是否打通"三个字段列，并清理相关不再使用的代码。

## Current State Analysis
在 `src/pages/JobList/index.tsx` 中：
- 表格首列为复选框列（第 214–236 行），依赖 `selectedRowKeys` 和 `setSelectedRowKeys` 状态
- "画像描述"列位于第 332–337 行
- "业务部门简介"列位于第 339–344 行
- "是否打通"列位于第 358–363 行

在 `src/pages/JobList/mockData.ts` 中：
- `JobItem` 接口包含 `portraitDesc`、`deptIntro`、`isConnected` 字段
- mock 数据包含这三个字段的实际值

## Proposed Changes

### 1. `src/pages/JobList/index.tsx`
**What**：删除复选框列、"画像描述"、"业务部门简介"、"是否打通"四列的定义。
**Why**：用户要求表格不再展示这些列。
**How**：
- 删除首列（复选框列，第 214–236 行）
- 删除 `portraitDesc` 列（第 332–337 行）
- 删除 `deptIntro` 列（第 339–344 行）
- 删除 `isConnected` 列（第 358–363 行）
- 删除 `selectedRowKeys` 状态声明及 `setSelectedRowKeys` 相关引用
- 删除 `Checkbox` 从 `antd` 的导入
- 删除 `Checkbox` 从 `@ant-design/icons` 无相关引用，无需处理

### 2. `src/pages/JobList/mockData.ts`
**What**：从 `JobItem` 接口和 mock 数据中移除 `portraitDesc`、`deptIntro`、`isConnected` 字段。
**Why**：这些字段不再在列表中展示，保持数据定义与表格展示一致，避免冗余。
**How**：
- 从 `JobItem` 接口中删除三个字段声明
- 从所有 mock 数据条目中删除对应的键值对

## Assumptions & Decisions
- 仅移除列表展示列，不修改展开行内容（`expandedRowRender`）中可能引用的字段。
- mock 数据量保持 60 条不变，仅移除三个字段。
- 移除 `Checkbox` 的 `import`，因为复选框列是唯一使用 `Checkbox` 的地方。

## Verification Steps
1. 启动开发服务器，打开职位列表页面。
2. 确认表格首列现在是"职位名称"，不再显示复选框列。
3. 确认表格中不再显示"画像描述"、"业务部门简介"、"是否打通"三列。
4. 确认页面无编译错误，表格横向滚动条正常工作。
