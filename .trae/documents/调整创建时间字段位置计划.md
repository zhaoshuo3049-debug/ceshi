# 调整创建时间字段位置计划

## Summary
将表格中"创建时间"列的位置从当前位置（第 7 列，联系人之后）移动到"职位状态"列之后（即第 11 列之后），使其紧跟在职位状态后面展示。

在 `src/pages/JobList/index.tsx` 的 `columns` 数组中，当前列顺序为：
1. 职位名称
2. 客户名称
3. 行业赛道
4. 公司级别
5. 业务部门
6. 联系人
7. 创建时间 ← 当前位置

11. 是否为管理岗
12. 优先级
13. 职位状态 ← 目标前置列
14. 操作

## Proposed Changes

### 1. `src/pages/JobList/index.tsx`
**What**：将"创建时间"列的定义从联系人之后移动到职位状态列之后。
**Why**：用户要求创建时间字段在职位状态后面展示。
**How**：
- 删除当前位于第 261–267 行的"创建时间"列定义
- 在第 318 行（职位状态列结束位置）之后插入"创建时间"列定义

调整后的列顺序关键部分为：
```
... 优先级
职位状态
创建时间  ← 新位置
操作
```

## Assumptions & Decisions
- 保持"创建时间"列的原有配置不变（`width: 100`、`align: 'center'`）。
- 仅调整列的顺序，不修改列宽或其他样式。
