# 调整职位状态列位置计划

## Summary
将表格中"职位状态"列从当前位置移动到"客户名称"列之前，使其紧跟在"职位名称"列之后展示。

## Current State Analysis
在 `src/pages/JobList/index.tsx` 的 `columns` 数组中，当前列顺序为：
1. 职位名称
2. 客户名称
3. 行业赛道
4. 公司级别
5. 业务部门
6. 联系人
7. 所属职能
8. 工作地点
9. 职位级别
10. 是否为管理岗
11. 优先级
12. 职位状态 ← 当前位置
13. 创建时间
14. 操作

## Proposed Changes

### 1. `src/pages/JobList/index.tsx`
**What**：将"职位状态"列的定义从当前位置移动到"客户名称"列之前。
**Why**：用户要求职位状态列展示在客户名称前面。
**How**：
- 删除当前位于第 300–311 行的"职位状态"列定义
- 在第 222 行（职位名称列结束位置）之后、第 223 行（客户名称列开始位置）之前插入"职位状态"列定义

调整后的列顺序关键部分为：
```
职位名称
职位状态  ← 新位置
客户名称
行业赛道
...
```

## Assumptions & Decisions
- 保持"职位状态"列的原有配置不变（`width: 80`、`align: 'center'`、自定义 Tag 渲染）。
- 仅调整列的顺序，不修改列宽或其他样式。

## Verification Steps
1. 启动开发服务器，打开职位列表页面。
2. 查看表格表头顺序，确认"职位状态"列紧跟在"职位名称"列之后、"客户名称"列之前。
