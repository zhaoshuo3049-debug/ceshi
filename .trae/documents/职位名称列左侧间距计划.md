# 职位名称列左侧间距计划

## 1. 概要
为“职位名称”列（首列）增加合理的左侧间距，解决当前内容太贴左的问题，并确保列标题（表头）与单元格数据同时左对齐、保持统一缩进。

## 2. 现状分析
- 表格单元格默认 `padding: 12px 8px`，首列左侧只有 8px 内边距。
- 之前已移除 `.job-name-cell` 的额外 `padding-left`，导致职位名称文本与表格左边缘较近。
- 仅给单元格加内边距无法让表头同步缩进，因此需要同时作用于首列的 `th` 和 `td`。

## 3. 拟修改内容

### 3.1 `src/pages/JobList/styles.css`
- 在表格样式区域新增/修改选择器，为首列的表头和单元格统一添加左侧内边距：
  ```css
  .table-section .ant-table-thead > tr > th:first-child,
  .table-section .ant-table-tbody > tr > td:first-child {
    padding-left: 12px;
  }
  ```
- 保持 `.job-name-cell` 不再单独设置 `padding-left`，避免重复缩进。

### 3.2 其他文件
- 无需修改 `index.tsx`、`mockData.ts`、`JobFormDrawer.tsx`。

## 4. 假设与决策
- “首列”即当前职位名称列，通过 `:first-child` 伪类统一控制。
- 左侧间距采用 12px，与之前 `.job-name-cell` 的间距值一致，视觉上更协调。
- 不修改其他列的间距，保持列表其余部分不变。

## 5. 验证步骤
1. 表格首列“职位名称”的列标题和每一行数据左侧均增加 12px 间距。
2. 列标题与数据左对齐，缩进一致。
3. 其他列的间距保持不变。
4. 运行 `npx tsc --noEmit` 无类型错误（样式改动通常不影响类型检查，仍例行验证）。
