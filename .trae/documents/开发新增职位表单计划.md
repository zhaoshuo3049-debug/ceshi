# 开发新增职位表单计划

## Summary
在职位列表页面新增一个 Drawer 抽屉表单，用于创建新职位。表单包含列表中展示的所有字段，并额外增加"职位 JD"字段。提交后将新职位追加到 mock 数据列表中并刷新展示。

## Current State Analysis
- 技术栈：React 19 + TypeScript + Ant Design 6 + Vite
- 当前应用入口 `src/App.tsx` 仅渲染 `JobList` 组件，无路由配置
- `src/pages/JobList/index.tsx` 中"新增"按钮（第 573 行）目前无点击事件
- `src/pages/JobList/mockData.ts` 中 `JobItem` 接口定义了列表数据字段，但实际 mock 数据仍残留已移除字段（`portraitDesc`、`deptIntro`、`isConnected`）
- 当前列表展示的字段为：职位名称、职位状态、客户名称、公司级别、业务部门、联系人、工作地点、职位级别、是否为管理岗、优先级、创建时间

## Proposed Changes

### 1. 新增 `src/pages/JobList/JobFormDrawer.tsx`
**What**：创建抽屉表单组件。
**Why**：将表单逻辑独立封装，便于维护，与列表页面解耦。
**How**：
- 使用 Ant Design 的 `Drawer`、`Form`、`Input`、`Select`、`DatePicker`、`Button` 等组件
- 定义 props：`visible`、`onClose`、`onSubmit`
- 表单字段及组件映射：
  | 字段 | 组件 | 说明 |
  |---|---|---|
  | 职位名称 | Input | 必填 |
  | 职位状态 | Select | 选项：进行中、已暂停、已关闭，默认"进行中" |
  | 客户名称 | Input | 必填 |
  | 公司级别 | Select | 选项：大厂、中厂、小厂 |
  | 业务部门 | Input | 必填 |
  | 联系人 | Input | 必填 |
  | 工作地点 | Input | 必填 |
  | 职位级别 | Input | 必填 |
  | 是否为管理岗 | Select | 选项：是、否 |
  | 优先级 | Select | 选项：一级、二级、三级 |
  | 创建时间 | DatePicker | 默认当天，格式化为 `YYYY.MM.DD` |
  | 职位 JD | TextArea | 新增字段，4 行高度 |
- 提交时对日期字段进行 `dayjs` 格式化
- 提交时生成 `id`（使用当前时间戳）和 `isNew: true`

### 2. 修改 `src/pages/JobList/index.tsx`
**What**：引入抽屉组件，为"新增"按钮绑定打开事件，并实现提交回调。
**Why**：让用户可以通过页面上的"新增"按钮打开表单，并将新数据加入列表。
**How**：
- 新增 `drawerVisible` 状态控制抽屉显隐
- 给"新增"按钮添加 `onClick={() => setDrawerVisible(true)}`
- 在页面中渲染 `<JobFormDrawer />`
- 实现 `onSubmit` 回调：将新职位 `unshift` 到 `mockJobList` 数组开头，关闭抽屉，重置页码到 1

### 3. 修改 `src/pages/JobList/mockData.ts`
**What**：在 `JobItem` 接口中新增 `jobDescription` 字段，并清理残留字段。
**Why**：保持数据模型与表单、列表展示一致。
**How**：
- 在接口中新增 `jobDescription?: string;`
- 删除 mock 数据中残留的 `portraitDesc`、`deptIntro`、`isConnected` 键值对

### 4. 修改 `src/pages/JobList/styles.css`
**What**：添加抽屉表单的基础样式。
**Why**：统一表单布局，保证字段间距合理。
**How**：
- 添加 `.job-form-drawer` 相关样式，设置表单字段间距、按钮组布局
- 可选：设置 Drawer 宽度为 520px

## Assumptions & Decisions
- 表单使用 Drawer 从右侧滑出，宽度 520px，适合字段较多的场景。
- 提交数据直接修改内存中的 `mockJobList`（因为当前无后端接口），刷新后即可看到新职位。
- `id` 使用时间戳生成，`isNew` 固定为 `true`，`createTime` 默认当天。
- "职位 JD"字段为新增字段，仅在表单中录入，列表中不展示。
- 表单字段均必填（创建时间有默认值）。

## Verification Steps
1. 启动开发服务器，打开职位列表页面。
2. 点击右上角"新增"按钮，确认 Drawer 抽屉从右侧滑出。
3. 填写表单各字段，点击"确定"提交。
4. 确认抽屉关闭，新职位出现在列表顶部，且字段值正确。
5. 检查 `mockJobList` 中是否包含 `jobDescription` 字段。
