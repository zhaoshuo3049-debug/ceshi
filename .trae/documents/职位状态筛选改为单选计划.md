# 职位状态筛选改为单选计划

## 1. 概要
将“职位状态”筛选组件从多选（`mode="multiple"`）改为与“优先级”一致的单选下拉，宽度、样式、交互保持统一。

## 2. 现状分析
- `src/pages/JobList/index.tsx` 中 `statusFilters` 为 `string[]`，默认值为 `['进行中']`。
- UI 使用 `Select mode="multiple"` 渲染，已选标签中会为每个选中状态生成一个筛选标签。
- “优先级”为单选 `Select`，状态类型为 `string | undefined`，无默认值。

## 3. 拟修改内容

### 3.1 `src/pages/JobList/index.tsx`
- 状态调整：
  - 将 `statusFilters: string[]` 重命名为 `statusFilter: string | undefined`。
  - 默认值保持为 `'进行中'`（保留原有初始过滤行为）。
- 筛选 UI 调整：
  - 移除 `mode="multiple"`。
  - `value={statusFilter}`，`onChange={setStatusFilter}`。
  - 保持 `placeholder="请选择"`、`allowClear`、`style={{ width: 160 }}`，与优先级一致。
- 过滤逻辑调整：
  - `filteredData` 中由 `statusFilters.includes(item.jobStatus)` 改为 `item.jobStatus === statusFilter`。
- 已选筛选标签调整：
  - 将 `statusFilters.forEach(...)` 循环生成标签改为单个标签：
    - `key: 'statusFilter'`
    - `label: 职位状态: ${statusFilter}`
    - `onRemove: () => setStatusFilter(undefined)`
- 清空按钮调整：
  - `setStatusFilters([])` 改为 `setStatusFilter(undefined)`。

### 3.2 其他文件
- 无需修改 `styles.css`、`mockData.ts`、`JobFormDrawer.tsx`。

## 4. 假设与决策
- “保持一致”指交互形式与优先级相同：单选、允许清空、宽度 160px。
- 默认值仍保留为“进行中”，避免初始列表展示全部职位状态，与现有体验一致。
- 清空所有筛选时，职位状态恢复为未选（undefined），与其他单选筛选一致。

## 5. 验证步骤
1. “职位状态”下拉变为单选，不再出现多选标签。
2. 选择“已暂停”后，列表只展示已暂停职位，已选筛选区域显示 `职位状态: 已暂停`。
3. 点击“清空”，职位状态筛选被清除。
4. 页面初始加载时，职位状态默认为“进行中”，列表只展示进行中职位。
5. 运行 `npx tsc --noEmit` 无类型错误。
